# milind2135.github.io

Personal portfolio of **Milind V. Chavan**, Cybersecurity Manager.

A single static page (plain HTML/CSS/JS): no build step, no framework, no cookies, no trackers.

## Files
| File | Purpose |
|---|---|
| `index.html` | The whole site |
| `Milind_Chavan_Resume.pdf` | Downloadable résumé |
| `.well-known/security.txt` | RFC 9116 security contact |
| `.nojekyll` | Tells GitHub Pages to serve `.well-known/` as-is |
| `robots.txt` | Allows search engines |

## Deploy (GitHub Pages)
1. Create a public repo named `Milind2135.github.io`.
2. Upload every file in this folder, including `.nojekyll` and `.well-known/`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
4. Renew the `Expires:` date in `security.txt` each year.

## Updating
Edit `index.html` directly on GitHub (pencil icon) and commit. The site updates in about a minute.
